# 评论区灵感地图

小红书 Lite Hackathon AI Demo：用 AI 语义理解评论区，把分散的追问、避坑、求链接、长期反馈聚合为可浏览的需求地图。

## Demo 体验路径

1. 打开 `index.html`。
2. 在单屏手机页面内上下滑动浏览笔记和评论。
3. 点击评论区顶部的“AI 看评论”，在评论区内展开语义分类。
4. 切换“场景追问 / 信任判断 / 决策需求 / 内容需求”，查看对应评论和洞察。
5. 在底部输入框发表评论；底部点赞、收藏、评论按钮固定不动，分享入口在顶部关注按钮右侧。

## 产品价值

- 用户：少翻大量评论，快速找到适合自己场景的真实经验。
- 创作者：把评论中的隐性需求转化为下一篇选题。
- 社区：用评论连接内容，让真实经验更容易被再次消费。

## 可落地范围

首期不做自动发文，只做公开评论的语义聚类、摘要、猜你喜欢召回和创作者选题建议。核心指标可观察 AI 入口点击率、评论区停留时长、猜你喜欢点击率、创作者二次发布率。
